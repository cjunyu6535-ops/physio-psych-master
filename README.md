# 🤗 面相分析大師 · 掐指一算成大師 (`physio-psych-master`)

結合東方《麻衣神相》千年相學智慧（三停、五官、十二宮、流年氣色）與西方現代心理學（Big Five 大五人格、FACS 微表情肌肉慣性、認知偏差），透過四階段互動狀態機與 Python 量化分析引擎，提供溫暖、高 EQ 且非宿命論的深度性格解析與心理成長建議。

## 專案結構

- `SKILL.md`：技能主體與四階段互動工作流定義
- `assets/gem_prompt_spec.yaml`：易讀版類 Markdown 系統規範架構（YAML-in-Markdown）
- `references/traditional_physiognomy.md`：《麻衣神相》三停、五官、十二宮與動態氣色多維知識庫
- `references/psychological_profiling.md`：Big Five 大五人格、FACS 微表情與高 EQ 非宿命論轉譯辭典
- `scripts/physio_psych_analyzer.py`：面部特徵與三停比例 -> 大五人格與心理韌性量化運算引擎
